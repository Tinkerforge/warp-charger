# §9 EEG
The `p9_eeg` module configures the feed-in limitation according to §9 of the German Renewable Energy Sources Act (EEG). The power limit of the grid operator is converted into one of the levels 0 %, 30 %, 60 % or 100 % of the inverter's rated power. The level is passed via the relays of the Energy Manager to the inverter's input for ripple control receivers. The highest level that complies with the limit is always used. If no relay is closed, 100 % always applies.
