# §9 EEG
Über das `p9_eeg`-Modul wird die Einspeisebegrenzung gemäß §9 des Erneuerbare-Energien-Gesetzes (EEG) konfiguriert. Das Leistungslimit des Netzbetreibers wird in eine der Stufen 0 %, 30 %, 60 % oder 100 % der Nennleistung des Wechselrichters umgerechnet. Die Stufe wird über die Relais des Energy Managers an den Eingang des Wechselrichters für Rundsteuerempfänger gegeben. Es wird immer die höchste Stufe gewählt, die das Limit einhält. Ist kein Relais geschlossen, gilt immer 100 %.
