# Einführung

Die WARP4 Ladesäule ist eine freistehende Montagemöglichkeit für eine oder zwei
[WARP4 Charger](/warp4/introduction.md) Wallboxen. WARP4 Charger Smart und Pro
können beliebig kombiniert werden. Die Wallboxen werden separat bestellt.

![WARP4 Ladesäulen mit montierten Wallboxen und Kabelhaltern](/img/warp4_stand/stand_versions.jpg)

Die Säule besteht aus 2 mm starkem, verzinktem Stahl mit DB703-Pulverbeschichtung
und ist mit der Schutzart IP54 für den Außenbereich geeignet. Sie wird in
Deutschland gefertigt. Die mitgelieferte, vormontierte Montagehilfe positioniert
die Befestigungsgewinde im Betonfundament. Die Befestigung der Säule erfolgt von
innen. Über die geteilte Rückwand sind die Zuleitungen zugänglich.

## Varianten

- **Für eine Wallbox:** Aufnahme auf der Vorderseite; das obere Rückenteil ist geschlossen.
- **Für zwei Wallboxen:** Je eine Aufnahme auf Vorder- und Rückseite.

Die Variante für eine Wallbox kann durch Austausch des oberen Rückenteils gegen
ein Teil mit den passenden Öffnungen und Befestigungspunkten für eine zweite
Wallbox umgerüstet werden. Bei der Variante für zwei Wallboxen müssen beide
Wallboxen montiert werden; die zweite Aufnahme darf nicht offen bleiben.

Die WARP4 Ladesäule ist ausschließlich für WARP4 Charger vorgesehen. Informationen
zum Vorgängermodell findest du unter [WARP Ladesäule](/warp_ladesäule/introduction.md).

## Optionales Verteilergehäuse

Die Säule kann **mit oder ohne Verteilergehäuse und Kabelanschlussset** bestellt
werden. Das optionale Gehäuse ist für eine oder zwei Wallboxen mit Hutschiene,
Klemmen und einem RJ45-Hutschienen-Patchkabelverbinder ausgestattet. Dazu gehören
die passenden Anschluss-, Erdungs- und Patchkabel.

Das Verteilergehäuse bietet auch Platz für zusätzliche Komponenten wie einen
Ethernet-Switch oder LTE-Router. Ohne dieses Set müssen die Anschluss- und
Erdungsleitungen für die Installation entsprechend bereitgestellt werden.

## Zugriffsschutz

Beide Rückenteile sind mit jeweils zwei Verschlussriegeln ausgestattet. Sie
werden mit dem mitgelieferten Schaltschrankschlüssel geöffnet. Zum Entfernen des
oberen Rückenteils muss zuerst das untere entfernt werden. Die Verschlussriegel
können optional durch Schlösser ersetzt werden.
